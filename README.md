# Информационная система «Магазин электроники»

Курсовой проект по МДК.01.01 «Разработка программных модулей».
Тема: **Разработка информационной системы для магазина электроники**.

## Описание

Настольное приложение для магазина электроники «Вольт»: каталог техники с поиском и фильтрами,
персональные цены со скидкой, оформление заказов с контролем складских остатков, журнал заказов
для сотрудников, ведение каталога, отчёт о продажах и управление пользователями.

### Основные функции

1. **Вход по логину и паролю**, регистрация покупателя или продолжение как гость; ФИО и роль — справа в шапке.
2. **Каталог** — карточки из БД, совместный поиск по наименованию и артикулу, фильтр по категории, сортировка по цене, заглушка при отсутствии фото.
3. **Индикация остатка** — «много» при остатке > 5, иначе «мало»; красная карточка при остатке ≤ 3.
4. **Скидка 25 %**, если в прошлом календарном месяце клиент не покупал товары этой категории.
5. **Оформление заказа** — только партии с остатком > 0, проверка количества, списание остатка одной командой `UPDATE` в транзакции, историческая цена в позиции.
6. **Заказы** — клиент видит свои, сотрудники — все; менеджер удаляет заказ (товар возвращается на склад), администратор меняет дату и удаляет отдельные позиции.
7. **Товары** (менеджер, администратор) — товары, партии и остатки; **Отчёты** — выручка за период по категориям/товарам; **Пользователи** (администратор) — учётные записи и роли.

## Технологии

* C# (.NET 10), Avalonia UI 12
* Microsoft SQL Server 2025, Entity Framework Core 10 (Database First)
* Git

## Запуск

1. В SSMS создайте пустую базу `electronics_store` (Collation — `Cyrillic_General_CI_AS`) и выполните `database/database_script.sql`.
2. Укажите свой сервер в `src/ElectronicsStore/connection.txt` (по умолчанию `Server=.`, для Express — `Server=.\SQLEXPRESS`).
3. Откройте `src/ElectronicsStore/ElectronicsStore.csproj` в Visual Studio и нажмите Ctrl+F5 (или `dotnet run` в папке проекта).

Тестовые учётные записи (пароль у всех — `1234`): `admin` (администратор), `manager`, `kuznetsov` (менеджеры),
`ivanov`, `smirnova`, `petrov`, `volkova`, `sokolov` (клиенты).
